## 2026-10-21

### 交互与状态反馈

- 为单选预设增加即时选中反馈，后续由主控状态校准，跟踪开关继续等待实际应答
- 操作结束后开启 5 秒快速反馈窗口，状态刷新间隔为 250 ms
- 保持单个在途状态请求、命令优先和页面隐藏暂停，慢响应不叠加请求
- 辅助滑块拖动时实时更新读数，拖动期间避免轮询覆盖，松手后沿用原提交流程
- 方向停止首次完整收到 HTTP 200 后跳过重复停止包，失败或未完成时保留保底重发
- 收紧设置开关点击范围，统一触控和键盘焦点样式

### 网络恢复

- 修复 STA 空闲掉线后无法恢复的问题，短暂断线先允许 SDK 恢复
- 已保存网络断线 30 秒后补充后台连接，后台超时后再等待 30 秒继续恢复
- 热点有客户端时暂缓主动重连，关闭 STA 开关后停止恢复
- 区分手动配网失败和后台恢复失败，手动失败不反复发起连接

### 点击响应、分块合并与栈帧优化

- 导航和 AJAX 小片段按 768 字节阈值合并，结束时统一发送余量
- 补齐编码器接口尾部发送，轴参数选项改为整项生成后发送
- 替换 51 处整段 HTML 格式化，清理 18 个函数的 240 字节临时缓冲
- 复用请求参数和静态选项表，缩小轴查询命令缓冲
- 修复辅助页温差 HTML 的 80 字节临时缓冲截断风险
- 保留原卡片业务、设备参数和串口查询顺序

- 修正图标延迟补绘和模拟页面首次打开时的导航入口

### 配网与无线恢复

- 进入网络页或切页返回时只读取状态，搜索由刷新按钮或首次开启且没有已知网络时触发
- 手动连接和后台连接期间暂停扫描，阻止扫描打断 STA 关联
- 拒绝旧页面的自动扫描和过期轮询请求，避免无效请求操作无线接口
- 恢复单次连接与 SDK 自动恢复，连接等待窗口为 25 秒，不重复调用连接入口
- 手动连接失败后保留已有热点与 STA 接口，仅关闭 STA 开关时关闭 STA
- STA 开关意图单独提交，新密码与网络参数仅在连接成功后保存
- 原样保存热点或网络设置时不重复写入、不重启热点
- STA 启动连接前应用小写 DHCP 主机名，状态接口补充运行时间和诊断信息

### 抱闸、采样与存储

- 将抱闸策略、采样适配、GPIO 与网页操作拆分为独立模块
- 驱动故障、失联或反馈过期时先发送停止运动和关闭跟踪命令，再等待有效静止反馈
- 停止失败后每隔 2 秒重试，每轮连同首次最多尝试 3 次
- 增加常驻手动解锁，立即松闸并暂停自动逻辑，不检查驱动状态或恢复原运动
- 故障仅保留在本次运行内存中，重新上电后重新查询，不沿用旧故障记录
- 驱动状态与保护流程共用新鲜反馈，反馈失效时显示未知
- 调整采样优先级并在完整事务之间让出调度，修复页面工作期间健康反馈过期导致的误停
- 修复关键设置立即提交、写入失败重试和时钟回绕处理
- 移除按抱闸状态过滤运动命令的路径，保持网页、TCP 和串口命令转发

### 参数、内存与工程结构

- ESP-07S 热点掉线、暂时无法重新加入、切页卡顿和偶发空白仍需真实设备验证
