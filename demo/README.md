# 本地网页演示

在电脑上预览 SmartWebServer 的界面与操作流程，使用模拟设备数据，不连接真实主控或机械设备

## 目录用途

`demo/` 保存演示程序与本说明，开发指南和修改日志统一放在 `docs/`

| 文件 | 用途 |
| --- | --- |
| `server.cjs` | 本地 HTTP 服务、页面路由与模拟状态接口 |
| `render.cjs` | 读取固件模板并生成演示页面 |
| `simulation.js` | 浏览器中的模拟交互 |
| `auxiliary.cjs` | 辅助通道的模拟状态与操作 |

仓库只跟踪本说明，演示脚本、测试工具、依赖与生成文件仅保留在本地

仅检出仓库时不会获得完整演示程序，需要本地已具备上述脚本及配套的 `tests/` 工具才能运行

## 准备环境

- 安装 Node.js
- 安装 g++ 并加入 PATH，部分真实页面模板需要在预览启动时编译
- 保留本地演示脚本及其依赖的测试工具
- 浏览器界面检查另需安装测试依赖和 Edge

演示直接使用固件模板，不需要安装 Vue 或单独构建前端

## 启动与停止

在仓库根目录运行

```powershell
node demo/server.cjs
```

浏览器打开 <http://127.0.0.1:8765/>，停止服务时按 Ctrl+C

默认只监听本机，调整端口时先设置环境变量

```powershell
$env:SWS_DEMO_PORT = '8768'
node demo/server.cjs
```

## 演示内容

- 控制器、赤道仪、网络、调焦器、旋转器、辅助设备和编码器页面
- 固件的实际样式、图标、导航、语言文字和卡片模板
- 原生页面切换、表单、浏览器前进后退和手机布局
- 跟踪、坐标输入、位置与限位编辑、网络扫描和点选连接的模拟交互
- 辅助通道开关、输出比例、除露与间隔拍摄的模拟反馈
- 活动灯、自动锁定、手动解锁等板载功能的界面展示

页面中的数值与功能组合由模拟环境提供，不代表某一台真实设备的配置或当前状态

演示中的运动、固件上传、重启与星表操作仅模拟反馈，不控制真实设备或写入固件

## 本地检查

以下命令同样在仓库根目录运行，浏览器检查需要已安装对应依赖

| 内容 | 命令 |
| --- | --- |
| 页面导航、历史和手机布局 | `node tests/native-navigation.cjs` |
| 首屏绘制和脚本延迟 | `node tests/native-first-paint.cjs` |
| 导航图标 | `node tests/native-icon-paint.cjs` |
| 辅助通道页面 | `node tests/auxiliary-page.cjs` |
| 辅助通道交互与截图 | `node tests/auxiliary-ui.cjs <输出目录>` |

生成页面、临时编译文件、浏览器配置与截图统一放在 `tests/output/` 下，不加入版本控制

模拟环境可检查模板、接口和浏览器行为，真实无线、串口响应与抱闸动作仍需实机验证
