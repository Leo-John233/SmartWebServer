# SWS 可点击模拟网页

本目录只跟踪本说明，演示脚本及其测试、依赖和输出均为本地开发工具。以下命令适用于本地已保留这些文件的环境，实际固件编译和 GitHub 合并不依赖演示工具。

在仓库根目录运行 `node demo/server.cjs`，浏览器打开 http://127.0.0.1:8765

- 需要 Node.js 和 PATH 中的 g++，也可用 CXX 指定编译器
- 可用 SWS_DEMO_PORT 设置其他端口，默认只监听本机
- 使用当前固件的样式、图标和控件模板，轴参数由实际 C++ 页面代码生成
- 模拟全部七个导航标签，默认进入已登录状态
- 标签直接使用原生页面链接，导航与内容位于同一文档，不使用 iframe 或 view 参数
- 页头由实际 C++ 的 pageHeader 生成，样式位于 head，脚本延后执行，延迟脚本或禁用脚本时也可使用导航和手机更多菜单
- 跟踪开关、倍率和高级设置直接运行固件卡片生成函数，方位控制标题在 PC 和手机统一为无冒号
- 基础样式和网络样式与固件一样复用浏览器缓存，图标直接随页头输出，不再等待单独的 SVG 请求
- 可展开设置、保存参数、点击移动和定位按钮、体验首次开启新网络时搜索与手动刷新，切页只读取状态
- 加密 Wi-Fi 输入至少八位模拟密码即可连接，输入 wrongpass 可体验连接失败
- 参数保存在浏览器本地存储，Wi-Fi 状态在服务重启后恢复
- 页面控件按模拟设备组合展示，数值与功能组合不代表特定实机配置
- 辅助设备执行真实 C++ 页面生成逻辑，演示配置开关输出、模拟输出、除露加热和间隔拍摄四个独立通道，其他通道关闭
- 辅助通道保留原有请求与状态接口，支持开关、输出百分比、除露参数、拍摄张数、曝光和间隔的模拟反馈，曝光与间隔使用固件的时间转换表
- 移动、固件更新、重启和星表操作仅模拟反馈，不连接硬件或写入真实固件

停止前台服务时按 Ctrl+C

入口检查：`node tests/native-navigation.cjs`，覆盖原生标签切换、缓存、浏览器历史、运动停止等待和桌面手机布局

首屏检查：`node tests/native-first-paint.cjs`，检查脚本延迟前后页头、导航和正文起点保持一致，以及禁用脚本时的手机更多菜单

图标检查：`node tests/native-icon-paint.cjs`，检查 PC 和手机首次绘制时的图标、连续切页无外部 SVG 请求及样式延迟时的底色

辅助页检查：`node tests/auxiliary-page.cjs`；交互与桌面、手机截图：`node tests/auxiliary-ui.cjs <输出目录>`
